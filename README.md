🌸 Flower Classification

A Deep Learning web application that classifies flower images into 5 categories using a CNN model.


🌼 Classes
Daisy
Dandelion
Roses
Sunflowers
Tulips


🛠️ Technologies

Python | TensorFlow/Keras | CNN | Flask | HTML | CSS


🚀 Run Locally
pip install -r requirements.txt
python app.py

Open in browser:

http://127.0.0.1:5000
